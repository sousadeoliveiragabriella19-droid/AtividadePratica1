O projeto a seguir é a pratica da busca BSF e DSF. Essas buscas são utilizadas em algoritmos para encontrar elementos solicitados dentro do algoritmo. 
O projeto solicitado se trata de um sistema de rotas de metro. Com esse sistrema é possivel verificar a melhor rota para chegar no destino, baldeações e simulações de caminhos no caso de estações ou linhas fechadas.
